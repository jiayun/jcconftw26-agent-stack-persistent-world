# 存檔管理

到「設定 → 存檔管理」可查看全部存檔的名稱、故事天數、章節、所在地及結局。正在使用的存檔會標示「目前使用」；名稱相同時可用末尾的短識別碼區分。

1. 用名稱搜尋，或直接瀏覽清單。
2. 勾選個別存檔；「勾選顯示項目」只選取目前搜尋結果中可刪除的項目。變更搜尋不會自動清除原有勾選，可按「清除勾選」重選。
3. 若要保留進度，先按該列「匯出」。每個檔案是一個可透過「匯入為獨立存檔」還原的故事備份。
4. 按「刪除已選的 N 個存檔」，檢查確認畫面上的完整清單，再選「確認永久刪除」。按「取消」或 Escape 不會刪除。

刪除會移除故事進度、記憶、回合紀錄、狀態變更紀錄及連線權杖。匯出的備份保存故事狀態，不包含原始回合 trace
或連線權杖。若刪除目前存檔，頁面會切換到另一個存檔；全部刪完則回到開始畫面。

正在處理回合的存檔暫不可刪除。若其他分頁或 MCP 已更新存檔，伺服器會保留整批資料並要求重新確認。可按「重新整理清單」取得最新狀態。

刪除只在本機 Web 管理介面提供，MCP 的五個故事工具沒有刪除權限。
