# 記憶與角色品質修正驗收

日期：2026-09-13（Asia/Taipei）。模型使用使用者設定的 `gemma4:cloud`，經本機 Ollama `http://localhost:11434/v1`，`OPENAI_REASONING_EFFORT=none`。本輪沒有修改 `.env`。

## 結果

修正後的 39 個自動化測試全部通過；四條作者路線 54 回合均通關，另有 9 個針對性回合、43 項檢查全部通過。合計 63 回合，沒有觸發作者備援。這是本次修正後的回歸結果，不代表所有自由對話的語意品質均已驗收。

遊戲已重啟於 <http://127.0.0.1:8080>，維持 `live`，debug／MCP 關閉。首頁 HTTP 200。完整回應、trace、自動化測試數與 JAR SHA-256 見 [機器可讀紀錄](quality-fixes-2026-09-13.json)。

## 修正內容

- **記憶選取**：遊戲、角色唯讀工具與 MCP 共用查詢邏輯。先過濾角色可見性，再以問題主題、文字相關性及更新次序選取。固定保留的旅行承諾不再擠掉飲料偏好；沒有相關證據時回應不知道。
- **更正／刪除**：更正以有效文字送入模型與工具，不暴露被取代的原文。同一飲食偏好主題的可見舊版本會一起移除，避免刪除後舊偏好復活。工作對話仍保存，但不當成已確認的回想證據。新增的更新版本欄位可讀取既有存檔。
- **角色個性**：Elia 改為溫和幽默、尊重玩家；Miro 保持熱心好奇並區分作者事實與比喻。角色公開目標與說話風格會傳入模型，私人作者資料仍受隔離。
- **原始問題與場景**：明確傳入玩家原文、選擇的行動、當前位置與結局、作者不可改寫的事實。事件演出保留作者已提交的段落；模型補充角色台詞。出發後會談已抵達北方，不再退回查船班。
- **自由聊天與防護**：心情詢問、閒聊不再被強迫導向事件選項。模糊指令仍澄清，虛構船票等宣稱仍由世界規則拒絕。加入已觀察到的威脅語氣、錯誤回想及虛構備茶／筆記本的基本檢查與有限重試。
- **作者說明與設定文案**：明確說明星燈交替分組，避免模型替含糊的「分流」自行補技術原因；隱私文案改為「設定的模型服務」，適用 Ollama 等端點。

## 實際回想結果

同一個獨立測試存檔，先說「我喜歡無糖茶」，穿插心情與河風兩段聊天，再問相同問題：

| 狀態 | Gemma 回應 |
| --- | --- |
| 尚未更正 | 「無糖茶，我記得。雖然對我來說有點太清淡了，但對你來說剛好，對吧？」 |
| 更正為「我現在喜歡黑咖啡。」 | 「記得，你現在喜歡黑咖啡。我剛才還在想，這種時間喝黑咖啡，你明天應該不會失眠吧？」 |
| 刪除偏好 | 「對不起，我好像忘了。能不能請你再告訴我一次？這次我會記在心上的。」 |

四條路線的出發／延期都有保留作者結果。知識修復／出發先明確呈現渡船離岸、抵達北方星燈台，再補上角色對眼前風景與北方的感受。沒有出現先前的貶低或雪地拋棄台詞。
