# 詢問角色意見的意圖修正

日期：2026-09-13。使用既有 `.env` 的 `gemma4:cloud`。本輪未修改 `.env`，變更基於 `3fa9b8f`。

## 問題與修正

「Elia 你說怎麼辦？」應請角色提出看法，不應執行事件。先前意圖辨識雖提到一般提問可用 chat，卻沒有充分區分詢問意見與要求行動，也沒有驗證模型產生的 actionId。未知行動因此直接流入世界裁決，顯示「這個行動目前不可用」。原失敗回合未保存模型的意圖原文，無法確認當時產生的具體 ID。

現在明確定義詢問意見為 chat，即使句子提及合法事件或移動仍應先回答問題。模型輸出的行動只能是目前事件選項、chat、rest 或已知地點的 move ID；未知 ID、字串 null、缺少澄清或同時包含行動與澄清時，使用同一回合預算修復一次。仍無法確認就自然澄清，避免把模型輸出問題呈現為玩家操作錯誤。意圖修復使用專用提示，不再套用敘事修復文案。

角色演出也明確限制詢問意見時只能提出看法或建議，不能聲稱已替玩家決定或執行。合法明確行動仍送往世界規則，過期事件按鈕與未滿足條件的移動仍被拒絕。

## 驗收

- `./gradlew test`：44 個測試通過，零失敗。新增 5 個意圖測試，涵蓋多種未知輸出修復、重試耗盡、澄清、合法事件與移動，以及非法移動與過期按鈕。
- `./gradlew :server:bootJar`：成功。
- `scripts/live_advice.py`：兩個獨立存檔（旅館／舊橋），四種問法各測兩次，共 8 個意見詢問回合；另外 4 個回合驗證澄清、非法移動、事件按鈕及明確移動。81 項檢查全部通過。
- `scripts/live_quality.py`：原有 9 回合、43 項檢查全部通過，涵蓋自由聊天、偏好回想、更正及刪除。
- 兩個 live 腳本合計 21 回合、36 次模型請求、SDK 回報 37,273 tokens，零作者備援。
- 正常重啟後首頁 HTTP 200，live 模式、debug／MCP 關閉；58 個存檔摘要與重啟前一致。本輪新增 3 個獨立測試存檔。

旅館中輸入「Elia 你說怎麼辦？」得到：「我還在思考，可能得花一點時間整理一下。如果你不介意，我們可以先慢慢討論，不用急著決定。」相近問法「Elia，你有什麼建議？」、「你會怎麼選？」、「你覺得要去渡口嗎？」也都正常回應。八次詢問都只更新對話記憶與 revision，時間、位置、旗標、關係、章節等世界狀態未變；沒有新增事實記憶。明確說「去渡口吧。」則正常移動。

這些案例驗證了本次失敗模式與控制邊界；語意分類仍由模型完成，並非保證所有自由輸入永遠分類正確。詢問意見的台詞有些仍較籠統，本輪不把趣味性或建議深度宣稱為已解決。
