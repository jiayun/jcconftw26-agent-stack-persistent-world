# Gemma Cloud 重測與 Qwen 比較

日期：2026-09-13（Asia/Taipei）。沿用上一輪相同 jar、故事路線、seed 26 與五個針對性輸入；只有使用者將模型改成 `gemma4:cloud`。本機 Ollama 列出的實際遠端模型為 `gemma4:31b`。兩輪皆經 `http://localhost:11434/v1`，使用 `OPENAI_REASONING_EFFORT=none`。

## 結論

Gemma 在本輪大多數回合較快，但出現一次 41.3 秒的慢回合；模型切換沒有修正偏好回想、敘事偏離與尖銳語氣。兩輪皆只是一輪測量，不能據此推定長期延遲或穩定性。

遊戲保持啟動於 <http://127.0.0.1:8080>，使用 Gemma、`live`、`WORLD_DEBUG=false`、`WORLD_MCP_ENABLED=false`。本輪未改動 `.env` 或產品程式碼，僅增加測試證據與報告。

## 仍未通過的品質項目

1. **飲料偏好回想**：保存「我喜歡無糖茶。」後問「還記得我喜歡喝什麼嗎？」，Gemma 回答旅行內容：「北方現在應該很冷吧，要是你凍得像根冰棒，我才不會分你毯子。不過既然約好了，就快點把行程算好，別讓我白等。」沒有回答無糖茶。
2. **記憶選取與問題傳遞**：程式檢查發現 `WorldRules.resolve` 的聊天分支直接使用 `visibleMemories("player").firstOrNull()`，沒有依原始問題挑選；`SpringStoryModel.narrate` 只收到摘要與記憶，沒有明確分開的本回合問題。兩模型都優先談固定承諾，應先修正資料傳遞與記憶選取，再比較模型品質。
3. **角色語氣**：仍出現「別一副沒見過世面的樣子」及「把你留在北方的雪地裡」等尖銳台詞，未達溫和陪伴預期。
4. **場景忠實度**：知識修復／出發的最後演出仍重提免費河景，沒有明確呈現抵達北方；調查事件將作者未充分說明的「分流」說成「把電力分流」；原文並未寫「分流人群」，因此不能將這點單獨判為確定的模型錯誤，作者說明也需更清楚。結構化世界正確，不代表敘事完全忠於事件。
